# Tiny Shakespeare

- **Source:** [`karpathy/char-rnn`](https://github.com/karpathy/char-rnn) (`input.txt`)
- **Shape:** a **single document** (~1.1M characters) — the complete works of Shakespeare.
- **Boundaries:** none (one document, so no `<|endoftext|>`).
- **Used by:** the first baselines (`baseline/lstm`, `baseline/gpt`).

### Excerpt

```
First Citizen:
Before we proceed any further, hear me speak.

All:
Speak, speak.

First Citizen:
You are all resolved rather to die than to famish?

All:
Resolved. resolved.
```
