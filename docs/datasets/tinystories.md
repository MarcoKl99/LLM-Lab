# TinyStories

- **Source:** [`roneneldan/TinyStories`](https://huggingface.co/datasets/roneneldan/TinyStories)
- **Shape:** many short children's stories, **one per document**, separated by `<|endoftext|>`.
- **Used by:** the TinyStories baselines and the model / data / compute scaling sweeps.

### Examples

```
Once upon a time there was a magical knee. It was so rare that none of the other
knees in the world knew about it. But the knee was special. Whenever someone
shrank and put their foot on it, they would go on a wonderful adventure. ...
```

```
Tom and Sam are friends. They like to play with cars and balls. One day, they
find a big box in the yard. They want to make a boat with the box.

"Let's tie the box to the tree," Tom says. "Then we can pretend we are sailing
on the water." ...
```
